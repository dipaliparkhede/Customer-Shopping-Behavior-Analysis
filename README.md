
# Customer-Shopping-Behavior-Analysis
Customer Shopping Behavior Analysis 🛍️  An end-to-end Data Analytics project that analyzes customer purchasing patterns, product performance, discounts, subscriptions, customer loyalty, shipping methods, and revenue.  

🔧 Technologies
Python
Pandas
Jupyter Notebook
PostgreSQL
PowerBI 

📊 Power BI Dashboard

The interactive dashboard analyzes:

💰 Total Revenue & Average Purchase Amount
👥 Customer Segments
🛍️ Product & Category Performance
⭐ Average Review Ratings
📦 Shipping Performance
🔄 Subscription & Customer Loyalty

🔄 Workflow

Raw Data → Data Cleaning → Feature Engineering → PostgreSQL → SQL Analysis → Business Insights
